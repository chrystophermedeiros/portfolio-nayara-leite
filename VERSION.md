# Version 2.0.0

Responsive section-aware layout refinement.

- Fluid desktop/tablet sizing per section
- Larger content on wide displays without forced clipping
- Carousel sizing derived from available section width
- Native touch scrolling for horizontal galleries while vertical page scrolling remains available
- Mobile galleries use compact 1–2 item presentation
- Grids use `minmax(0, ...)` to prevent horizontal overflow
